# I.Chie Prototype Bundle

This local bundle includes a generated prototype `I.Chie.sff` built from the user-provided front reference image plus the DEF/CMD/CNS/AIR text foundation.

The GitHub draft PR keeps the high-resolution source art and derived sprite archive out of the public branch until redistribution rights and runtime verification are confirmed.

Dragon shop/NPC content:
- `I.Chie_shopkeeper_pose.png` is a derived saleswoman pose that keeps the current prototype head, hair, body, legs, and palette.
- `I.Chie.sff` includes shopkeeper sprite `9100,0`.
- `I.Chie.air` includes action `9100`.
- `I.Chie.cns` includes non-combat state `9100`.
- `I.Chie.dragon.def` marks the character as a shop saleswoman and points shop code at action/state `9100`.

Do not add `I.Chie` to `game/data/select.def` until:
- `I.Chie.sff` is accepted into the repo or generated by the asset pipeline
- the character loads in Training
- the character loads in VS
- the character loads in Single Player
- `python engine/tools/dev_check.py . --skip-build` passes
