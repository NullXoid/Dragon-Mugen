# A.Ben Prototype Bundle

This owned prototype bundle includes:

- `A.Ben.sff`
- `A.Ben.air`
- `A.Ben.cmd`
- `A.Ben.cns`
- preview portrait/icon images
- derived prototype action PNGs under `generated_actions/`

The current walk cycle comes from the accepted A.Ben walk frame source. Dash, jump, punch, kick, special, and super sprites are derived bridge frames generated by `engine/tools/build_aben_action_sff.py` so the character no longer falls back to the old front-facing placeholder during combat.

These action sprites are functional prototype art, not final authored combat animation. Replace the generated groups with final source frames when the A.Ben animation set is ready.

Useful checks:

- `python engine/tools/audit_mugen_compat.py game`
- `build/dragon_mugen.exe --verify roster-compatibility-smoke`
- `build/dragon_mugen.exe --verify kfm-movement-direction-audit`
- `python engine/tools/dev_check.py . --skip-build`
