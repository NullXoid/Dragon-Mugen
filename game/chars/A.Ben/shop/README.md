# A.Ben Shop Assets

Shop presentation assets for A.Ben live here so the shop and fighter presentation share the same character folder.

- `shop_player_back_pose.png`: current rear-facing shop pose.
- `walk/shop_player_walk_*.png`: shop walk frames generated from the same curated walk source used by `A.Ben.sff`.

The legacy `game/data/shop/shop_player_*` files may exist as compatibility fallback, but new runtime loading should prefer this folder.
